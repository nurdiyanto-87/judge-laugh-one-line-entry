A tiny Python program that writes one original funny line to `/output/entry.txt`: a job interview derailed by dead Wi-Fi, finished by carrier pigeon — and the pigeon gets the job, with better references. The laugh lands twice, on the last clause.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
